# Задание 4-2: Отображение файлов в память mmap()

**Запуск:**
1. `gcc -Wall -Wextra -o task task.c`
2. `./task`

**Результат:** Программа создает файл со строкой "AAAAA", мапит его в память через `mmap()`, меняет первый байт на 'Z', производит `munmap()`. При повторном чтении файла стандартным `read()` видно, что строка стала "ZAAAA", что доказывает сохранение изменений.
