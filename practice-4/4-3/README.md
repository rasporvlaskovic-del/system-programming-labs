# Задание 4-3: Демоны

**Запуск:**
1. `gcc -Wall -Wextra -o task task.c`
2. `./task`
3. `ps aux | grep task` (найти PID демона)
4. `kill -TERM <PID>`
5. `cat /tmp/daemon_iter.log`

**Результат:** Программа успешно демонизируется (двойной `fork()`, `setsid()`, закрытие потоков ввода-вывода). Лог пишется в `/tmp/daemon_iter.log`. При получении сигнала `SIGTERM` цикл прерывается и файл корректно закрывается.
