# Задание 1-4: Диагностика процессов (Вариант 7)

## Описание задания
1. Запустите процесс `sleep 100; echo "Done"` в фоновом режиме.
2. Найдите PID этого процесса.
3. Используйте команду `cat /proc/[PID]/stat`, чтобы проверить информацию о процессе.
4. Отправьте сигнал `SIGTERM` с помощью команды `kill`, чтобы завершить процесс.
5. Проверьте, что процесс больше не существует с помощью команды `ps -p`.
6. Все команды и результаты сохраните в файл `commands.txt`.

## Инструкция по запуску
1. Установите права на выполнение для скрипта:
    ```bash
    chmod +x script.sh
    ```
2. Выполните скрипт:
    ```bash
    ./script.sh
    ```

## Ожидаемый результат
Программа должна выполнить следующие шаги:
- Запустить процесс `sleep 100; echo "Done"`.
- Вывести информацию о процессе через `/proc`.
- Завершить процесс с помощью `kill`.
- Проверить завершение процесса и записать все команды и результаты в файл `commands.txt`.

Файл `commands.txt` должен содержать:
