# Задание 1-4: Диагностика процессов - Вариант 7

## Описание задачи

В этом задании необходимо:
1. Запустить процесс `sleep 100`.
2. Найти его PID с помощью команды `ps aux | grep sleep`.
3. Вывести содержимое файла `/proc/[PID]/status` для получения информации о процессе.
4. Отправить сигнал `SIGTERM` с помощью команды `kill [PID]`, чтобы завершить процесс.
5. Проверить завершение процесса.

Задача включает работу с процессами, их идентификаторами и управление процессами с помощью сигналов.

## Шаги выполнения

1. **Создание процесса**:
   Для создания дочернего процесса используется `fork()`, после чего в дочернем процессе выполняется команда `sleep 100`.

2. **Получение PID процесса**:
   В родительском процессе выводится PID дочернего процесса.

3. **Просмотр состояния процесса**:
   Родительский процесс открывает файл `/proc/[PID]/status` для получения информации о состоянии дочернего процесса.

4. **Завершение процесса**:
   Родитель отправляет сигнал `SIGTERM` дочернему процессу с помощью команды `kill`, чтобы завершить его.
