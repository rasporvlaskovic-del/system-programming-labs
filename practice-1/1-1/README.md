Задание 1-1, Вариант 7:

Создать файл binary.txt с '0' и '1' (100+ символов), подсчитать единицы, записать в ones.txt.

Для этого нужно написать программу на языке C, которая будет:

Создавать файл binary.txt, в котором будут записаны 100 символов ('0' и '1').

Подсчитывать количество единиц ('1') в этом файле.

Записывать результат в файл ones.txt.

Шаги выполнения:

Создайте файл task.c с кодом

Компиляция программы:
Чтобы скомпилировать программу, используйте команду:

gcc -Wall -Wextra -o task task.c


Запуск программы:
После компиляции, запустите программу:

./task


Результат:
Программа создаст файл binary.txt, который будет содержать 100 символов '0' и '1'. Затем она подсчитает количество единиц и запишет результат в файл ones.txt.
