# Задание 1-1: Системные вызовы (Вариант 7)

## Описание задания
В этом задании требуется создать файл `binary.txt` с символами '0' и '1' (100+ символов). Программа должна подсчитать количество единичных символов ('1') в этом файле и записать результат в файл `ones.txt`. Все операции должны быть выполнены с использованием системных вызовов: `open()`, `read()`, `write()`, `close()`.

## Инструкция по запуску
1. Создайте файл `binary.txt`, содержащий хотя бы 100 символов '0' и '1'. 
2. Программа должна прочитать этот файл, подсчитать количество единичных символов ('1') и записать результат в файл `ones.txt`.

## Компиляция
Для компиляции программы используйте следующую команду:
    ```bash
    gcc -Wall -Wextra -o task task.c

## Запуск программы
Для запуска введите в терминале следующую команду:
    ```bash
    ./task

## Ожидаемый результат
После выполнения программы в файле ones.txt будет записано количество символов '1' в файле binary.txt.
