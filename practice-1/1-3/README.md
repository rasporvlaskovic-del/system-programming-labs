# Задание 1-3: Файловая система и права - Вариант 7

## Описание задачи

В данном задании необходимо:
1. Создать файл `large.txt` размером 1 МБ (с использованием команды `dd if=/dev/zero of=large.txt bs=1M count=1`).
2. Разбить файл на части по 100 КБ с помощью команды `split -b 100k`.
3. Собрать файл обратно с помощью команды `cat`.

Задача требует работы с файлами и системными утилитами, такими как `split` и `cat`.

## Шаги выполнения

1. **Создание файла `large.txt` размером 1 МБ**:
   Для создания файла размером 1 МБ используется команда `dd` или программа на языке C для записи нулей в файл.

2. **Разбиение файла на части по 100 КБ**:
   Используется команда `split -b 100k` для разделения файла на части по 100 КБ.

3. **Объединение файла обратно**:
   Для восстановления исходного файла используется команда `cat`, которая объединяет части в один файл.
