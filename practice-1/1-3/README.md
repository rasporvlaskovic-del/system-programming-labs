# Задание 1-3: Файловая система и права (Вариант 7)

## Описание задания
Создайте директорию `mydir`, внутри нее 5 файлов с разными правами доступа:
- `file1.txt` — права 644
- `file2.txt` — права 755
- `file3.txt` — права 600
- `file4.txt` — права 444
- `file5.txt` — права 700
После этого выполните команду `ls -l mydir`, чтобы отобразить права файлов.

## Инструкция по запуску
1. Сначала установите права на выполнение для скрипта:
    ```bash
    chmod +x script.sh
    ```
2. Для выполнения скрипта используйте команду:
    ```bash
    ./script.sh
    ```

## Ожидаемый результат
Программа создаст директорию и файлы с указанными правами, затем выведет результат команды:
-rw-r--r-- 1 user user 0 Feb 6 12:00 file1.txt
-rwxr-xr-x 1 user user 0 Feb 6 12:00 file2.txt
-rw------- 1 user user 0 Feb 6 12:00 file3.txt
-r--r--r-- 1 user user 0 Feb 6 12:00 file4.txt
-rwx------ 1 user user 0 Feb 6 12:00 file5.txt
