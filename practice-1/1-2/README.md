# Задание 1-2: Процессы fork/exec (Вариант 7)

## Описание задания
В этом задании родительский процесс создает 2 дочерних процесса. Первый дочерний выполняет команду `ps aux`, а второй — команду `date`. Родительский процесс ждет завершения обоих дочерних процессов и выводит сообщение "Оба дочерних процесса завершены".

## Инструкция по запуску
1. Для компиляции программы используйте команду:
    ```bash
    gcc -Wall -Wextra -o task task.c
    ```
2. Для выполнения программы используйте команду:
    ```bash
    ./task
    ```
