# Задание 1-2: Процессы fork/exec - Вариант 7

## Описание задачи

В этом задании необходимо создать родительский процесс, который создает дочерний процесс. Дочерний процесс создает файл `child.txt` и записывает в него строку "Hello from child". Родительский процесс должен прочитать содержимое файла `child.txt` и вывести его в терминал. Для синхронизации работы процессов используется функция `wait()`, чтобы родительский процесс дождался завершения дочернего перед тем, как продолжить выполнение.

## Шаги выполнения

1. **Создание родительского процесса с помощью `fork()`**:
   - Родительский процесс создает дочерний с помощью функции `fork()`.
   
2. **Дочерний процесс**:
   - Дочерний процесс создает файл `child.txt` с помощью функции `open()` и записывает строку "Hello from child" в этот файл.
   - Дочерний процесс завершает выполнение с помощью `exit()`.

3. **Родительский процесс**:
   - Родительский процесс вызывает `wait()`, чтобы дождаться завершения дочернего процесса.
   - После завершения дочернего процесса родитель открывает файл `child.txt` и выводит его содержимое в терминал.

## Требования

- Использование функций системных вызовов:
  - `fork()`: для создания дочернего процесса.
  - `open()`, `write()`, `close()`: для работы с файлом в дочернем процессе.
  - `wait()`: для ожидания завершения дочернего процесса в родительском процессе.
  
## Как скомпилировать и запустить программу

1. Скомпилировать программу с помощью GCC:
   
   gcc -Wall -Wextra -o task task.c
   
2. Запустить программу:

    ./task
