# Задание 2-2: Синхронизация с мьютексами (Вариант 7)

## Описание задания
Есть два счета:
- `account1 = 500`
- `account2 = 500`

Создайте 10 потоков, каждый из которых переводит 10 единиц с `account1` на `account2`. Мьютекс защищает операции перевода. Ожидаемый результат: после выполнения программы на `account1` будет 400, на `account2` — 600.

## Инструкция по запуску
1. Компиляция:
    ```bash
    gcc -pthread -o task task.c
    ```
2. Выполнение:
    ```bash
    ./task
    ```

## Ожидаемый результат
После выполнения программы в консоли должны быть выведены итоговые значения счетов:
- Final account1: 400
- Final account2: 600
