# Задание 2-2: Синхронизация с мьютексами - Вариант 7

## Описание задачи

В этом задании необходимо создать 8 потоков. Каждый поток генерирует случайное число `rand()%1000`. Потоки обновляют глобальную переменную `max`, если сгенерированное число больше текущего значения. Для синхронизации доступа к переменной `max` используется мьютекс.

Задача включает использование многопоточности с библиотекой `pthread` и синхронизации через мьютексы.

## Шаги выполнения

1. **Создание потоков**:
   Каждый поток генерирует случайное число, и если оно больше текущего значения `max`, обновляет его. Доступ к переменной `max` синхронизируется с помощью мьютекса.

2. **Использование мьютекса**:
   Для защиты переменной `max` от одновременного доступа используется мьютекс. Это предотвращает состояние гонки и обеспечивает корректное обновление `max`.

3. **Ожидание завершения всех потоков**:
   После создания всех потоков главный поток ожидает их завершения и выводит финальное значение переменной `max`.

## Как скомпилировать и запустить программу

1. Скомпилировать программу:
   ```bash
   gcc -Wall -Wextra -pthread -o task task.c

2. Запустить программу:
   ```bash
   ./task

### Ожидаемый результат:

Программа должна создать 8 потоков, которые генерируют случайные числа.

Все потоки синхронизируют доступ к глобальной переменной max.

В конце программы будет выведено максимальное значение, найденное среди случайных чисел.
