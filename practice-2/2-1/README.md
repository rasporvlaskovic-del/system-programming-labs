# Задание 2-1: Многопоточность (Вариант 7)

## Описание задания
Создайте 3 потока. Каждый поток выполняет команду:
- Первый поток выполняет `ls > thread1.txt`.
- Второй поток выполняет `date > thread2.txt`.
- Третий поток выполняет `whoami > thread3.txt`.
После завершения потоков, главный поток читает все файлы (`thread1.txt`, `thread2.txt`, `thread3.txt`) и выводит их содержимое.

## Инструкция по запуску
1. Компиляция:
    ```bash
    gcc -pthread -o task task.c
    ```
2. Выполнение:
    ```bash
    ./task
    ```

## Ожидаемый результат
После выполнения программы, в консоли должны отобразиться содержимое файлов `thread1.txt`, `thread2.txt`, и `thread3.txt`, каждый из которых содержит результат выполнения соответствующих команд:
- Contents of thread1.txt:
[вывод команды ls]

- Contents of thread2.txt:
[вывод команды date]

- Contents of thread3.txt:
[вывод команды whoami]
