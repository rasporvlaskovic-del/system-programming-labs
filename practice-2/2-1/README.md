# Задание 2-1: Многопоточность - Вариант 7

## Описание задачи

В этом задании необходимо:
1. Создать 3 потока, каждый из которых выполняет одну из команд:
   - `ls > thread1.txt`
   - `date > thread2.txt`
   - `whoami > thread3.txt`
2. Главный поток должен прочитать все файлы и вывести их содержимое.

Задача включает создание потоков с использованием библиотеки `pthread` и выполнение команд через `system()`.

## Шаги выполнения

1. **Создание потоков**:
   Для создания потоков используется библиотека `pthread`. Каждый поток выполняет свою команду, которая записывает вывод в соответствующий файл.

2. **Чтение файлов**:
   После выполнения всех потоков главный поток читает файлы `thread1.txt`, `thread2.txt` и `thread3.txt`, и выводит их содержимое.

## Как скомпилировать и запустить программу

1. Скомпилировать программу:
   ```bash
   gcc -Wall -Wextra -pthread -o task task.c
2. Запустить программу:
   ```bash
   ./task.c
