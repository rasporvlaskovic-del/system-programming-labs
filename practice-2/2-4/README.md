# Задание 2-4: Отладка с strace - Вариант 7

## Описание задачи

В этом задании необходимо:
1. Запустить программу с использованием `sleep(5)`, чтобы создать задержку.
2. Использовать `strace` с флагом времени (`-t`) для отслеживания системных вызовов.
3. Найти вызовы `nanosleep()` или `clock_nanosleep()` в выводе `strace`.
4. Проверить время сна, указанное в системных вызовах.

Задача включает использование инструмента `strace` для отладки и анализа системных вызовов, связанных с задержками выполнения программы.

## Шаги выполнения

1. **Запуск программы**:
   Программа вызывает `sleep(5)`, что заставляет её засыпать на 5 секунд.

2. **Использование `strace` для отслеживания системных вызовов**:
   Для отслеживания всех системных вызовов, включая `nanosleep()` и `clock_nanosleep()`, используйте команду `strace`(предварительно сделайте установку strace с помощью команды "sudo apt install strace"):
   ```bash
   strace -t ./task

3. **Поиск вызовов `nanosleep()` или `clock_nanosleep()`**:
В выводе strace найдите строки с вызовами `nanosleep()` или `clock_nanosleep()`, чтобы проверить время сна.

## Как скомпилировать и запустить программу

1. Скомпилировать программу
   ```bash
   gcc -Wall -Wextra -o task task.c

2. Запустить программу с использованием `strace`:
  ```bash
 strace -t ./task

### Ожидаемый результат

Программа будет засыпать на 5 секунд.

В выводе strace будет показан вызов nanosleep() или clock_nanosleep(), где будет указано время сна.
