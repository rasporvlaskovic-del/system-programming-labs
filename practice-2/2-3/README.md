# Задание 2-3: Обработка сигналов (Вариант 7)

## Описание задания
1. Программа создает 3 дочерних процесса.
2. Родительский процесс ждет завершения дочерних через `wait()`.
3. Обработчик сигнала `SIGCHLD` подсчитывает завершенные процессы.
4. После завершения всех дочерних процессов родитель выводит сообщение "X child processes completed".

## Инструкция по запуску
1. Компиляция:
    ```bash
    gcc -o task task.c
    ```
2. Выполнение:
    ```bash
    ./task
    ```

## Ожидаемый результат
После выполнения программы, родительский процесс должен вывести:
Child process completed
Child process completed
Child process completed
All child processes completed
