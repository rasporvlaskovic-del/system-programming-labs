# Задание 2-3: Обработка сигналов - Вариант 7

## Описание задачи

В этом задании необходимо:
1. Программа должна создать файл `pidfile.txt` и записать в него PID текущего процесса.
2. Программа должна работать в бесконечном цикле, пока не получит сигнал `SIGTERM`.
3. При получении сигнала `SIGTERM` программа должна закрыть файл и удалить его, а затем завершиться.

Задача включает обработку сигналов с помощью функции `signal()` и работу с файлами.

## Шаги выполнения

1. **Создание файла `pidfile.txt`**:
   Программа создает файл `pidfile.txt`, записывает в него свой PID с использованием `getpid()`.

2. **Обработка сигнала `SIGTERM`**:
   Программа обрабатывает сигнал `SIGTERM` с помощью функции `signal()`. Когда сигнал получен, программа закрывает и удаляет файл `pidfile.txt`, а затем завершает выполнение.

3. **Завершение работы программы**:
   После получения сигнала `SIGTERM` программа завершает свою работу.

## Как скомпилировать и запустить программу

1. Скомпилировать программу:
   ```bash
   gcc -Wall -Wextra -o task task.c

2. Запустить программу:
   ```bash
   ./task

3. Отправить сигнал SIGTERM программе, где PID -ид процесса:
   ```bash
   kill -SIGTERM <PID>
   
### Ожидаемый результат:

Программа создаст файл pidfile.txt и запишет в него свой PID.

При получении сигнала SIGTERM программа удалит файл и завершит работу.
