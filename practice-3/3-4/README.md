# Задание 3-4: Диагностика сети

Команды и их результаты сохранены в файле `commands.txt`. При запуске двух процессов `http.server` на разных портах, утилита `netstat -tuln` четко показывает два TCP LISTEN сокета (на портах 8081 и 8082), привязанных к интерфейсу 0.0.0.0, что свидетельствует о готовности серверов принимать входящие соединения.
